## 二、改了哪些块

| 顺序 | 区块 | 数据来源 / 行为 |
|:--|:--|:--|
| ① | **AI 总管每日简报**（顶部） | 依据 `/api/state` 真实数据动态生成：项目总数 / 正常 / 停滞 / 待决策 / 待审批、最近真正完成（`actions` 中 `status=succeeded && checked`）、停滞与待决策项目名、`today 最该做的一件`、AI 自动推进数量。默认**规则引擎大白话**，绝不空着；模型不可用时仍完整。另有「✨ 让总管写一段」按钮，用户主动才调 `/api/chat`（提示词明确禁止执行/生成审批/调用工具），按 `revision+counts+last_patrol` 存 sessionStorage，数据一变自动回到最新规则版。**无固定演示文案、无每次刷新调模型** |
| ② | **全局可视化概览** | 6 张 KPI 卡（数字与 `counts` 一致，含未核实项目数说明）；纯 SVG 环形状态分布图（active/stalled/awaiting_decision/pending_acceptance 四色）；进度条；变化趋势用 `projects[].snapshots` 的真 `overall/at` 按日聚合，不足 2 个时间点时**明说「不绘制、不编造」**。无新库 |
| ③ | **项目卡片** | 中文名、当前阶段（首个未完成里程碑）、可验证完成率或**「待核实」**（`overall_verified=0` 绝不显示 0%/编数字）、已完成主要成果、下一步、阻塞/待决策数、AI 是否正在执行（`auto_advance` + 近期执行回执）、最近实质进展（`last_change`/`snapshots`）。颜色/进度条/图标区分四种状态；点卡片展开详情并能「问 AI 这个项目」；分类 chips 沿用 `setFilter` |
| ④ | **AI 对话助手** | 首页显眼深蓝卡片（非藏在技术菜单），四个可点快捷问句一字不差；完整对话页保留。`GET /api/chat/history` 渲染、**两个挂载点共享同一份历史与发送逻辑**、刷新后回来；`POST /api/chat` 原接口，回答与执行都不另造；高风险由后端拦截，前端不放行 |
| ⑤ | **技术详情降级** | 通知 / 审批 / 执行回执 / 系统事件 / 原始 JSON（按需点「载入」才显示）/ 9195 服务日志 iframe 全部收进 `<details>`「⚙ 高级设置 / 技术日志」，默认收起；首页不再有成片原始日志。二级页 `v-logs` 保留完整能力 |

**保留能力清单（全部接真接口，无摆设）**：`load / sel / setFilter / flip / pause / runAction / doPatrol / triggerAuto / decide`；六模块（首页、AI 对话、进展时间轴、待我拍板、高级设置/技术日志、主动提醒）；`/api/gantt` + `/api/gantt/rebuild`，本地静态 frappe-gantt 1.2.2；`setGanttView('Week'/'Month')` 用 `view_mode` 真切换；`unscheduled` 明标「待排期」，`scheduled` 明标「已发生进展时间轴，不是未来计划甘特」；点条 `showGanttDetail` → `openProject` 打开项目详情；`/api/auto-runs` GET；`/api/auto-runs/trigger` 仅手动；审批 approve/deny；双轨日志浮窗；5 秒自动刷新；`window.onerror` 上报。

**其他**：`fmtT()` 兼容实测的 `M/D/YYYY HH:MM:SS` 与 ISO 两种时间格式；`uid()` 只把安全字符拼进 onclick，项目名一律函数内查表（防注入破坏属性）；`dependencies` 数组/字符串双兜底；浅色现代 SaaS 配色、统一圆角/间距、`@media(max-width:640px)` 手机单列、`html/body{max-width:100%;overflow-x:hidden}`、`min-width:0` + `word-break` 防 390×844 横向溢出；加载 / 失败 / 空 / 等待审批状态均有明确提示。
